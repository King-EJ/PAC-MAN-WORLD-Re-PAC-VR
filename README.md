INSTALL
  unzip to game folder, only tested with virtual desktop XR

  Start the game with -force-d3d11 (Steam: right-click the game > Properties > Launch Options) - the game

**[Nefarius ViGEmBus](https://github.com/nefarius/ViGEmBus/releases) support - with the driver installed (ViGEmBusSetup_x64.msi in the zip) the VR
        controllers are a real virtual Xbox 360 controller ([Controls] InputMethod = Auto / ViGEm / InputSystem).**

CONTROLS (the VR controllers are an Xbox controller for the game - the game's own pad controls and prompts)
-
  Left stick ............ move (first person / follow: where you LOOK)
  
  Right stick ........... game camera: the game's camera / first person and follow: turns you (snap)
  
  Right stick UP ........ third person: switch FOLLOW / GAME CAMERA
  
  Right stick click ..... switch FIRST / THIRD PERSON
  
  Left stick click ...... START (pause)
  
  X + Y together .... BACK
  
  Left grip HELD + left stick ... D-PAD
  
  Left grip + Y ......... VR SETTINGS MENU (stick up/down choose, left/right change, A toggle, B close)
  
  Left grip + X ......... re-centre the view
  
  Every button can be changed in the config ([Controls.Pad]).

VIEW
  * Third person, game camera (default): you are where the game's camera is.
  * Third person, follow: behind Pac-Man at a fixed height; the right stick turns you.
  * First person: at Pac-Man's face; his arms follow your controllers. Walking goes where you look.
  * Menus / pause: the game's picture on a screen in front of you. Cut-scenes, stage start / goal: the game's camera.


Disable: to disable Mod rename winhttp.dll to winhttp.dll.bak
